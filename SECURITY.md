| Version | Supported          |
| ------- | ------------------ |
| 3.1.x   | :white_check_mark: |
| < 3.0   | :x:                |

---

## Reporting a Vulnerability

Security is paramount for download accelerators handling web requests and media parsing. If you discover a security vulnerability within Velotrap, please do **NOT** open a public issue.

Instead, please send an advisory report to the maintainers or report via GitHub Private Vulnerability Reporting:

1. Navigate to the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Detail the issue, steps to reproduce, affected versions, and any suggested fixes.

We strive to acknowledge receipt within 48 hours and provide a fix or mitigation promptly.
